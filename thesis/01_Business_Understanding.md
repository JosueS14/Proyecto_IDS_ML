
Decision 001
Se eligio un IDS con clasificacion binaria para determinar si la conexion es segura un un ataque malicioso
- Reduce la complejidad inicial
- Facilita el entrenamiento y la evaluacion del modelo
- Permite validar primero el validamiento del IDS

Decision 002
Se eligio el dataset CICIDS2017 para usar como dataset para entrenar y validar los datos
- Es un de los datasets mas  completos y utilizados para IDS
- Contiene una gran variedad de trafico normal  y malicioso
- Fue generado en un entorno controlado que simula una red empresarial
