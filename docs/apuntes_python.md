En python, una variable no alamacena necesariamente el valor directamente, sino que hace referencia a un objeto. Al asignar una variable a otra (x = y), ambas pueden referirse al mismo objeto o al mismo valor, dependiendo del tipo de dato. Este comportamiento sera especialmente importante para trabajar con estructuras mutables como listas y DataFrame de pandas.

- Una variable es un dato es un espacio de memoria identificado por un nombre, que almacena un valor y puede ser utilizado o modificado durante la ejecucion de un programa.
- Las variables en python no es necesario identicar  como se declara una variable (let, var, const), basta con asignar un valor y Python infiere el tipo automaticamente. En jascript si es necesario declarar las variables mediante let, var o const, aunque el tipo de valor tambien se infiere de forma dinamica.
- La identacion se refiere a el espacio que hay entre el inicio una linea con donde se empieza a escribir codigo. En python es importante porque su sintaxis, se utiliza para poder delimitar bloques de codigo, como condiciones, ciclos o funciones.
